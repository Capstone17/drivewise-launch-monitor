Welcome to my GitHub! I'm a Computer Engineering student in Canada with a strong focus on hardware-software co-design, predictive modeling, and network security protocols. 

### 🚀 Featured Engineering Projects

- **DriveWise Launch Monitor (Capstone Project):** Engineered the backend and edge-AI pipeline for a CV-powered golf launch monitor on a Raspberry Pi 5. Optimized and deployed YOLOv8 models using TensorFlow Lite/ONNX for 450+ FPS video capture, and built a rule-based AI feedback engine that streams low-latency swing analytics to a mobile app via BLE.
- **Dual-Core SoC Game Development:** Engineered a two-player bowling game on the Xilinx Zynq SoC platform utilizing the Vivado design suite. Implemented custom hardware IP blocks, VDMA framebuffer management, game physics, and complex audio-video synchronization.
- **Machine Learning for Game Strategy:** Built and trained an AI model using Keras to play Cribbage. Analyzed edge-card bias and combinatorial dead weight, achieving an 81% accuracy rate for discard predictions.
- **Automotive Network Security Research:** Conducted extensive simulation and analysis of CAN bus architecture vulnerabilities, benchmarking baseline traffic against dominant flood DoS and stealth spoofing attacks.
